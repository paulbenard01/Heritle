# Heritle 3D assets

Every model and photograph used by Heritle 3D is logged here before it is
committed, the same discipline the Wikidata and Commons photo sourcing already
follows. A model with no row in the table below does not ship.

## The rules

**Self-hosted, never embedded.** A Sketchfab iframe shows the model's title and
its author, which is the answer. Every model is downloaded, re-exported and
served from this directory.

**Anonymised on the way in.** The filename is `relic-NNN.glb`, and the mesh,
node and material names inside the file are generic. The stand-in photograph is
`relic-NNN.jpg`, downloaded and renamed rather than hot-linked — a Commons URL
carries the monument's name in plain sight in the network tab.

This is about not spoiling the puzzle in passing, not about secrecy. The
coordinates have to reach the browser for the game to work at all, exactly as
they do in the daily game, so anyone who opens the console can read the answer.
The bar is that a player is never *shown* the answer before earning it.

**Licence-vetted by hand.** CC0 or CC-BY only, and CC-BY means the attribution
line on the reveal screen is not optional. The row below is what fills it.

**Quality-vetted by hand.** Searching a famous monument on Sketchfab returns a
lot of low-poly fan art and voxel builds alongside the genuine photogrammetry.
Check the triangle count and the texture resolution, and prefer models with
institutional or serious-hobbyist provenance. A decorative game asset of a
monument teaches the player nothing about the monument.

**Budgeted before committing.** Decimate, compress textures to 2048 px at most,
Draco-compress the geometry, and land between 1 and 3 MB. GitHub's 100 MB
ceiling is not the budget: binaries do not delta-compress, so every re-export
adds a full second copy to the repository's history for ever. Get a model right
*before* the first commit rather than iterating in the repo.

**Fallbacks** when a monument has no good Sketchfab candidate: Smithsonian Open
Access 3D, Wikimedia Commons' 3D model category, Europeana 3D.

Every asset currently in this directory is a **placeholder**, generated by
`tools/make_placeholder_glb.py` and a few lines of PIL, so the guess → reveal
flow could be built and tested before any real asset existed. They are
deliberately abstract: a placeholder shaped like a building would be mistaken
for a real scan in a screenshot. Each is about 900 bytes (model) and 20 KB
(image).

Replacing one means: drop in the new files under the same names, fill in its
row above, and set `credit` in `data/relics.json` — dropping the
`"placeholder": true` flag, which is what marks a row as not yet real.
